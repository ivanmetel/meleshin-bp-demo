# Демо машины сборки КП — разделилось

Совмещённое демо (30.09–01.10) разделено на две страницы:

- **ЛК клиента** (смета, согласование, сохранение PDF) — <https://ivanmetel.github.io/meleshin-bp-client/> (репо `ivanmetel/meleshin-bp-client`);
- **Админка** (конструктор, документ, маркдаун, отчёт) — <https://ivanmetel.github.io/meleshin-bp-admin/> (репо `ivanmetel/meleshin-bp-admin`); движок, данные и опубликованное для клиента состояние (`published.json`) живут здесь.

Правки в админке влияют на ЛК клиента: опубликованное состояние ЛК грузит из репо админки, кнопка «Предпросмотр ЛК клиента» передаёт текущее состояние конструктора в адресе ЛК.

Страница этого репо перенаправляет в ЛК клиента.
